# 🛍️ Diwali Sales Analysis

## 📌 Project Objective

Analyze Diwali sales data to identify customer segments, product categories, and purchasing patterns that drive sales and support data-driven marketing decisions.

## 🎯 Business Problem

Businesses need to understand which customers, products, and regions contribute most to festive sales in order to optimize marketing campaigns and inventory planning.

## ⚙️ Actions

* Cleaned and prepared the dataset using Pandas.
* Performed exploratory data analysis (EDA) to uncover sales trends.
* Visualized customer demographics, product performance, and purchasing behavior using Matplotlib and Seaborn.
* Generated business insights and recommendations.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📂 Dataset

* **Source:** Kaggle – Diwali Sales Dataset
* **Records:** 11,000+ customer transactions

## 📊 Key Insights

* Married women aged **26–35** were the highest-spending customer segment.
* **Uttar Pradesh, Maharashtra, and Karnataka** generated the highest sales.
* Customers working in **IT, Healthcare, and Aviation** spent the most.
* **Food, Clothing, and Electronics** were the top-selling product categories.

## 💡 Recommendations

* Target festive campaigns toward high-value customer segments.
* Increase inventory for top-performing product categories.
* Focus promotions on high-revenue states and occupations.
* Personalize offers using customer demographics.
